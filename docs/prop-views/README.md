# Prop views

Review renders for the Stage G prop models, saved 2026-11-17
on Joey's instruction so they live in the repo (target/ is
scratch). Regenerate with:

    cargo run -p voxelizer --example prop_strips -- <pre-drive coverage TSV>

Each strip is [sprite, FRONT, BACK, LEFT, RIGHT] in the
preview renderer's 3/4 projections. Mockups are the
hand-drawn targets some models were generated from
(pipeline section 32 records which).

side-seats build (cone profile tried and rejected as
worse; the side views still read flat to Joey — question
of outline vs surface left open). Boulders, fungal clump,
kiln, gasper, barrels and the vat await Joey's verdicts
